核心业务 Agent

  - 会话总控 Agent
    负责意图识别、路由、串联多个专项 agent、汇总最终回复。它应该是用户侧唯一入口。
  - 需求管理 Agent
    负责创建、修改、补全、重写需求，并作为唯一写入 RequirementActor 的入口。
  - 质检 Agent
    对单条需求做完整性、可测试性、歧义性、一致性检查，输出结构化修改建议。
  - 冲突检测 Agent
    做跨需求冲突分析，比如目标冲突、约束冲突、术语冲突、版本冲突。
  - 需求抽取 Agent
    面向 Phase 1-3，把访谈文本、文档、上下文转成结构化需求草案。
  - 需求分类 Agent
    负责 L1/L2/L3/L4、功能/非功能、领域标签、优先级初判。
  - 需求追溯关系 Agent
    建立高层需求、低层需求、测试项、来源片段之间的 traceability。
  - 评审纪要 Agent
    把一次修改、质检、冲突分析结果整理成审计友好的变更说明。
  - 测试映射 Agent
    从需求生成验收标准、测试点、测试覆盖建议。
  - 基线变更 Agent
    专门处理已基线需求的变更申请、影响分析、审批建议。
  - 影响分析 Agent
    当某条需求变化时，分析影响到哪些下游需求、模块、测试、文档
  - 执行图观测 Agent
    负责解释运行图、挂起原因、失败节点、恢复建议。
  - 知识检索 Agent
    从 transcript、上下文、历史需求、项目资料里检索证据，供其他 agent 使用。
