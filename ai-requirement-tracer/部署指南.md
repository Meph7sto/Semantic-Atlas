# 需求追溯系统部署指南

## 部署准备

### 1. 服务器要求
- **GPU服务器**：推荐AutoDL或其他GPU云服务
- **显存要求**：至少8GB显存（用于DeepSeek-7B模型）
- **内存要求**：至少16GB RAM
- **存储空间**：至少50GB可用空间

### 2. 环境准备
```bash
# Python环境
Python 3.8+
CUDA 11.8+ (如果使用GPU)

# 系统包
git
wget
unzip
```

## 部署步骤

### 第一步：上传项目文件

#### 方案A：使用Git（推荐）
```bash
# 在服务器上克隆项目
git clone <your-repository-url>
cd ai-requirement-tracer
```

#### 方案B：直接上传
```bash
# 将整个 ai-requirement-tracer 文件夹上传到服务器
# 可以使用scp、FileZilla等工具
scp -r ai-requirement-tracer/ root@your-server:/root/
```

### 第二步：安装依赖

#### 后端依赖
```bash
cd /root/ai-requirement-tracer

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装Python依赖
pip install -r backend/requirements.txt

# 安装AI推理服务依赖
pip install fastapi uvicorn transformers torch torchvision torchaudio
pip install accelerate bitsandbytes safetensors
```

#### 前端依赖
```bash
# 安装Node.js (如果未安装)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装前端依赖
cd frontend
npm install
npm run build
```

### 第三步：模型准备

#### 下载DeepSeek-7B模型
```bash
# 创建模型目录
mkdir -p /root/autodl-tmp/models/su-model

# 下载模型文件（替换为实际的模型下载地址）
cd /root/autodl-tmp/models/su-model
wget <your-model-download-url>

# 或者从Hugging Face下载
pip install huggingface_hub
python -c "
from huggingface_hub import snapshot_download
snapshot_download(repo_id='deepseek-ai/deepseek-coder-7b-base', 
                 local_dir='/root/autodl-tmp/models/su-model')
"
```

### 第四步：配置服务

#### 1. 修改配置文件
```bash
# 修改后端配置
vim backend/config.py
# 确保数据库路径正确，API地址配置正确

# 修改FastAPI服务配置
vim fastapi_inference_server.py
# 确认模型路径: /root/autodl-tmp/models/su-model/
```

#### 2. 创建系统服务文件

**AI推理服务**
```bash
sudo vim /etc/systemd/system/ai-inference.service
```

添加以下内容：
```ini
[Unit]
Description=AI Inference Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/ai-requirement-tracer
Environment=PATH=/root/ai-requirement-tracer/venv/bin
ExecStart=/root/ai-requirement-tracer/venv/bin/python fastapi_inference_server.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**后端服务**
```bash
sudo vim /etc/systemd/system/requirement-backend.service
```

添加以下内容：
```ini
[Unit]
Description=Requirement Trace Backend
After=network.target ai-inference.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/ai-requirement-tracer/backend
Environment=PATH=/root/ai-requirement-tracer/venv/bin
ExecStart=/root/ai-requirement-tracer/venv/bin/python run.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

### 第五步：配置Nginx（前端服务）

#### 安装Nginx
```bash
sudo apt update
sudo apt install nginx
```

#### 配置Nginx
```bash
sudo vim /etc/nginx/sites-available/requirement-trace
```

添加以下配置：
```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或IP

    # 前端静态文件
    location / {
        root /root/ai-requirement-tracer/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api/ {
        proxy_pass http://localhost:5000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # AI推理服务代理
    location /ai/ {
        proxy_pass http://localhost:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_connect_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

启用站点：
```bash
sudo ln -s /etc/nginx/sites-available/requirement-trace /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 第六步：启动服务

```bash
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动并启用服务
sudo systemctl enable ai-inference.service
sudo systemctl enable requirement-backend.service
sudo systemctl enable nginx

sudo systemctl start ai-inference.service
sudo systemctl start requirement-backend.service
sudo systemctl start nginx

# 检查服务状态
sudo systemctl status ai-inference.service
sudo systemctl status requirement-backend.service
sudo systemctl status nginx
```

### 第七步：防火墙配置

```bash
# 开放必要端口
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 22/tcp
sudo ufw enable
```

## 常见问题解决

### 1. 模型加载失败
```bash

nvidia-smi

# 检查模型文件
ls -la /root/autodl-tmp/models/su-model/

# 查看AI服务日志
sudo journalctl -u ai-inference.service -f
```

### 2. 前端访问404
```bash

cd /root/ai-requirement-tracer/frontend
npm run build

# 检查Nginx配置
sudo nginx -t
sudo systemctl reload nginx
```

### 3. API连接失败
```bash
# 检查后端服务
sudo systemctl status requirement-backend.service
sudo journalctl -u requirement-backend.service -f

# 检查端口占用
netstat -tlnp | grep :5000
netstat -tlnp | grep :8000
```
