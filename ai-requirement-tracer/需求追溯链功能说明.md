# 需求追溯链功能说明

## 功能概述

基于您提供的测试集（`formatted_data.json`），我们已经实现了一个完整的需求追溯链分析系统。该系统可以：

1. **接受用户输入的顶层需求和底层需求**
2. **使用AI模型判断两个需求之间是否存在直接的追溯关系**
3. **如果存在关系，则在可视化界面中用连线显示**
4. **提供详细的关系分析报告**

## 测试集数据格式分析

您提供的测试集包含以下结构：
```json
{
  "instruction": "请判断以下高层需求和底层需求之间是否存在直接的追溯关系。请回答'是'或'否'。",
  "input": "高层需求：...\n底层需求：...",
  "output": "是" // 或 "否"
}
```

## 核心功能实现

### 1. 关系判断逻辑
AI模型会从以下几个方面分析需求关系：
- **语义相关性**：分析两个需求在语义上的关联度
- **实现关系**：底层需求是否实现了顶层需求
- **支持关系**：底层需求是否支持顶层需求的实现
- **依赖关系**：两个需求之间是否存在依赖
- **分解关系**：顶层需求是否分解为底层需求

### 2. 关系类型分类
- `implementation`: 实现关系
- `support`: 支持关系
- `dependency`: 依赖关系
- `decomposition`: 分解关系
- `general`: 一般追溯关系
- `unknown`: 未知关系

### 3. 可视化连线规则
- **有关系时**：显示从顶层需求到底层需求的连线
- **无关系时**：仅显示两个独立的节点
- **连线标签**：显示关系类型（如"实现关系"、"支持关系"等）
- **置信度显示**：通过进度条显示AI判断的置信度

## 使用步骤

### 1. 启动系统
```bash
# 1. 启动AI推理服务器
python fastapi_inference_server.py

# 2. 启动后端服务器
python backend/run.py

# 3. 启动前端服务器
cd frontend && npm run serve
```

### 2. 使用关系追溯功能
1. 打开浏览器访问 `http://localhost:8080`
2. 选择"关系追溯"模式
3. 在"顶层需求"框中输入高层需求
4. 在"底层需求"框中输入底层需求
5. 点击"分析追溯关系"按钮
6. 查看分析结果和可视化连线

### 3. 示例测试
可以使用测试集中的真实数据进行测试：

The DPU-BOOT CSC shall include a DRAM BIT consisting of two write/read/compare tests. The first test shall write the address of each memory location to that location. The second test shall write the complement of each memory location to that location.
```

**底层需求示例**：

DRAM BITPart of the memory is tested in Boot Sequence 1, and part of the memory is tested during Boot Sequence 2. During Boot Sequence 1, ? KB of DRAM is tested before the Bootstrap is copied to this area. During Boot Sequence 2, the remaining memory is tested in ? KB blocks.
```
